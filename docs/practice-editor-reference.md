# Practice editor reference

The current Add/Edit Practice workspace intentionally mirrors the uploaded `Nicks_Coaching_OS_Correct_Practice_Editing(1).html` editor behavior while preserving the newer Diagram Studio and session features.

Key behaviors retained:
- text form and Diagram Studio are visible together in one workspace;
- Diagram Studio opens automatically for new/edit practice flows;
- switching practices clears stale Diagram Studio state before loading the newly selected practice;
- the diagram title follows the practice name;
- mobile stacks the text form above the diagram editor.
